#+title: alegoria
Alegoria is a web aggregator for image galleries and collections from several hosting sites.

* Installation
There's a Docker Compose file available which you can run locally like this:

#+begin_src sh
cd /path/to/alegoria
docker compose up -d
#+end_src

* Configuration
You can edit the default gallery-dl [[file:src/frontend/public/config.json][config.json]] file locally with the [[https://gdl-org.github.io/docs/configuration.html][supported configuration options]], such as to change the extractors browser, the included subcategories, the order of posts, and so on.

* Development Setup
Enter the dev shell to install dependencies:

#+begin_src sh
nix develop
#+end_src

Then start the front-end and back-end processes with this:

#+begin_src sh
# Add `-- -D` if you want to detach the processes
nix run .
#+end_src

** Adding a new extractor
To add support for a new gallery-dl extractor, first inspect the API response shape by running the backend and hitting the posts endpoint:

#+begin_src sh
curl -s "http://localhost:5000/api/v1/posts/<url>" | jq .
#+end_src

Use the response to write the extractor mapping in [[file:src/frontend/src/page-schema.ts][page-schema.ts]].
